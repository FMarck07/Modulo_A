int main ( int argc,
char * argv[] )

Si scriva un programma C che: legga una sequenza di 10 interi e la memorizzi in un array; chieda all'utente attraverso una funzione con l'interfaccia int ordine() se vuole che la sequenza venga stampata nello stesso ordine di inserimento o in ordine inverso, che legga la risposta dell’utente (char 's' per stesso ordinamento, 'i' per ordinamento inverso); se l'utente inserisce un carattere diverso da 's' o 'i', la funzione deve chiedere nuovamente di inserire la risposta. stampi l'array nell'ordi.

Parameters
argcNumero di argomenti passati attraverso la riga di comando.
argvArray di stringhe contenente gli argomenti passati attraverso la riga di comando.
Returns
Restituisce 0 al termine normale dell'esecuzione; restituisce un valore diverso in caso di errore.
